# 🎮 Gaming Deals

**Discover the best gaming deals, discounts, and offers in one place.**

Gaming Deals is a web platform designed to help gamers find the best discounts on video games across multiple online stores.

Instead of checking different stores manually, users can discover current deals, compare prices, and navigate directly to the store where they can purchase their favorite games.

## ✨ Features

- 🔥 **Today's Best Deals** — Discover the best gaming discounts of the day.
- 💰 **Price Comparison** — Find game prices across different stores.
- 🏷️ **Discount Tracking** — Identify games currently on sale.
- 🔗 **Direct Store Links** — Visit the store and purchase games directly.
- ⚡ **Automatic Updates** — Python-powered price checking and deal collection.
- 🎮 **Gaming-Focused Design** — A simple and user-friendly interface.

## 🚀 Getting Started

### Requirements

- Python 3
- A modern web browser
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/gaming-deals.git
```

2. Navigate to the project directory:

```bash
cd gaming-deals
```

3. Install the required Python dependencies, if any.

4. Start the backend:

```bash
python server.py
```

5. Open the website in your browser using the local address configured by the server.
